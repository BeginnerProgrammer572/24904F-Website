# React Bits (vendored)

`LogoLoop.jsx` and `Masonry.jsx` are the free JavaScript + Tailwind variants from
reactbits.dev, under the license in `LICENSE.md`. Both are excluded from lint.

Local changes, to repeat if you update them:

- `Masonry.jsx`: tile images load lazily, the full-screen view uses `item.full`,
  corners are square, and Tab stays inside the full-screen view.
